## 🔴 Критические ошибки (ИСПРАВЛЕНЫ)

### 1. Несоответствие торговых часов
**Проблема:** Различные значения `TRADING_HOURS_PER_DAY` в разных модулях
```python
# Было в backtest.py
TRADING_HOURS_PER_DAY = 16

# Было в config.py  
TRADING_HOURS_PER_DAY = 15
```
**Исправление:** ✅ Унифицировано использование конфигурации

### 2. Ошибка в расчете комиссий
**Проблема:** Двойное деление на 100 для комиссии биржи
```python
# Было
exchange_cost = notional * self.exchange_commission_rate / 100
```
**Исправление:** ✅ Убрано лишнее деление на 100

### 3. Неправильный расчет notional для пар-трейдинга
**Проблема:** Использование суммы вместо максимума
```python
# Было
notional = abs(s1[i-1]) + abs(beta * s2[i-1])
```
**Исправление:** ✅ Изменено на `max()` для корректного пар-трейдинга

### 4. Неправильная обработка NaN в сигналах
**Проблема:** Пропуск NaN мог нарушить позиционирование
**Исправление:** ✅ Сохранение текущей позиции при NaN
